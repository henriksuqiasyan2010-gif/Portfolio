# HENRIK — sites that push back

Одностраничное портфолио в эстетике «ретро-терминал + неон»: Vite + TypeScript без фреймворка, three.js (один WebGL-контекст), GSAP + ScrollTrigger.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # проверка типов + сборка в dist/
npm run preview   # собранная версия на http://localhost:4173
```

## Где менять контент

Всё — имя, тексты, цифры, проекты, ссылки, email — лежит в [src/content.ts](src/content.ts). Разметка страницы собирается из этого файла при сборке, поэтому страница читается и без JavaScript. Остальной код трогать не нужно.

- Превью проектов: `public/projects/*.webp`, 800×500. Путь к картинке указывается в `content.ts`.
- Форма: если заполнить `contact.formEndpoint` (например, адресом Formspree), сообщения уходят туда. Если оставить пустым, открывается почтовый клиент (`mailto:` на `contact.email`).
- Пустые `demo` или `github` у проекта прячут соответствующую ссылку.

## Параметры адреса

| Параметр | Что делает |
|---|---|
| `?debug` | панель с FPS, уровнем качества и переключателем уровней |
| `?quality=low\|medium\|high` | принудительный уровень графики |
| `?nointro` | пропустить интро |

Клавиша `~` открывает консоль (`help`, `about`, `projects`, `open <id>`, `contact`, `theme amber|green`, `clear`, `exit` и пара пасхалок). На телефоне консоль открывается кнопкой `~` в футере.

## Как устроена графика

- Уровни качества High / Medium / Low выбираются по ядрам, памяти и видеокарте. Если средний FPS ниже 50 дольше 2 секунд, уровень понижается на ступень и обратно сам не поднимается.
- Частицы отталкиваются от курсора в вершинном шейдере: курсор каждые 50 мс оставляет «толчок», а смещение частицы — сумма откликов затухающей пружины на последние толчки. Поэтому частицы пружинят обратно без расчётов на CPU.
- Рендер останавливается в фоновой вкладке и когда ни частицы, ни глаз не видны на экране.
- Без WebGL или при потере контекста показываются CSS-звёзды и картинка `public/fallback/eye.webp` (рендер настоящего глаза).
- При `prefers-reduced-motion` нет интро, глитчей и скрамбла, частицы статичны, глаз двигается медленно и не моргает.
- На телефонах three.js загружается после первого касания или скролла, до этого фоном служат CSS-звёзды.

## Шрифты

Self-hosted woff2-сабсеты лежат в `public/fonts`: Silkscreen (латиница), Tiny5 (кириллица для пиксельных заголовков), JetBrains Mono. Лицензии OFL — рядом с файлами шрифтов.
